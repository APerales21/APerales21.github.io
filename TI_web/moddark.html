Página con modo nocturno

Haz clic en el botón para alternar entre claro y oscuro. La preferencia se guarda en tu navegador.

Contenido principal

Este es un ejemplo de página. El modo nocturno cambia variables CSS para que todo el sitio se adapte. Puedes personalizar los colores editando las --variables al inicio del CSS.

Atajo: presiona la tecla D para alternar el tema (útil para pruebas).

Acerca

La implementación usa data-theme en el elemento raíz para conmutar entre temas y localStorage para recordar la preferencia del usuario.
